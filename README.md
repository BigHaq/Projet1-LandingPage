# KINETIX ULTRA - Landing Page Premium

Une landing page haute performance pour une salle de sport d'élite, conçue avec une esthétique "High-Performance Noir" (Dark mode, Neon Green accents).

## 🚀 Technologies Utilisées

- **React 19** : Pour l'interface utilisateur réactive et modulaire.
- **Vite** : Pour un environnement de développement ultra-rapide.
- **Tailwind CSS v4** : Pour un stylisme moderne, performant et optimisé.
- **Stitch** : Pour la génération des designs haute fidélité initiaux.
- **Google Fonts** : *Bebas Neue* (Titres) et *Inter* (Corps de texte).
- **Material Symbols** : Icônes Google modernes.

## ✨ Fonctionnalités

- **Design Immersif** : Esthétique futuriste avec glassmorphism, grain d'overlay et lueurs néons.
- **Système de Réservation** : Interface interactive en 3 étapes (Discipline -> Horaire -> Confirmation).
- **Sections Modulaires** :
  - **Hero** : Introduction percutante.
  - **Programmes** : Grille de services avec données dynamiques.
  - **Coachs** : Présentation des experts avec effets premium.
  - **Témoignages** : Preuve sociale avec design "Glass-Deep".
  - **Tarifs** : Tableau comparatif clair et attractif.
- **Totalement Responsive** : Optimisé pour une expérience fluide sur tous les appareils.

## 🛠️ Installation et Utilisation

### Prérequis
- Node.js installé sur votre machine.

### Lancer le projet en local
1. Accédez au dossier du site :
   ```bash
   cd site
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
4. Ouvrez votre navigateur sur `http://localhost:5173`.

## 🌐 Déploiement (Vercel)

Ce projet est optimisé pour un déploiement sur **Vercel**.

1. Poussez votre code sur GitHub.
2. Connectez votre dépôt sur Vercel.
3. **IMPORTANT** : Dans les paramètres de Vercel, définissez le **Root Directory** sur `site`.
4. Vercel détectera automatiquement la configuration Vite et déploiera l'application.

## 📂 Structure du Projet

- `site/src/components` : Tous les composants UI.
- `site/src/data` : Données mockées (programmes, coachs).
- `site/src/index.css` : Jetons de design et styles globaux.
- `.stitch` : Historique des designs et prompts de génération.
